# 세무사 시험 준비 대시보드

세무사 수험에 자주 쓰는 사이트와 공부 도구를 한 곳에 모아둔 개인용 대시보드입니다.
[cpa-dashboard](https://github.com/goldie-ui/cpa-dashboard)(회계사용)를 복사해 만든 자매 사이트입니다.

## 수정 방법

`index.html` 위쪽 세 배열만 고치면 됩니다.

- `DATA` — 사이트 목록 `{name, url, desc}`
- `SUBJECTS` — 과목 `{name, color}`
- `QUOTES` — 명언 `{t, by}` (`QUOTE_MS`로 교체 주기)

push하면 약 40초 내 자동 배포됩니다.

## 기능

사이트 바로가기 · 즐겨찾기 · 검색 · D-day · 명언 자동 교체 ·
포모도로 타이머(완료 시 과목에 자동 적립) · 할 일 · 메모 ·
과목별 공부시간 잔디밭 · 라이트/다크 · 홈 화면 앱 설치 ·
기기 동기화 · 백업 내보내기/불러오기

## 기기 동기화

푸터의 **기기 동기화** → 한 기기에서 시작 → 나온 코드를 다른 기기에 붙여넣기.

| 항목 | 충돌 시 |
|---|---|
| 공부 기록 | 날짜·과목별 **더 큰 값** 유지 (합쳐짐) |
| 메모 · 할 일 · 즐겨찾기 · D-day | **마지막에 고친 쪽** |

동기화를 켜지 않으면 기록은 브라우저에만 남습니다. 켜면 Vercel Blob private 스토어에
저장되며, 동기화 코드를 SHA-256 해시한 경로를 쓰므로 저장소에 코드 원문은 남지 않습니다.

> ⚠️ 동기화 코드를 아는 사람은 기록을 볼 수 있습니다. 회계사용 대시보드와는 **별개의 코드**입니다.
